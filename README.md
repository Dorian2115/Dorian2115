## 💼 Featured Projects

### [portfolio-rag](https://github.com/Dorian2115/portfolio-rag) ⭐**
> **A Retrieval-Augmented Generation chatbot that answers questions about my CV and projects.**

Built with:
- **Backend:** Node.js, Express, TypeScript
- **AI:** OpenAI GPT-4o-mini, text-embedding-3-small
- **Frontend:** React + Vite + TypeScript
- **Database:** JSON vector store, cosine similarity search
- **Features:** Rate-limiting, bilingual support, evaluation pipeline, Docker support

A learning project demonstrating RAG architecture, document chunking, embeddings, and grounding LLM answers in actual sources.

🔗 [Portfolio RAG Chatbot Live Demo](https://github.com/Dorian2115/portfolio-rag)
